# Python OOP Foundations: 4-Part Lab Series

Welcome! This repository is a step-by-step learning journey designed to master Object-Oriented Programming (OOP) in Python. 

It consists of lightweight spikes / proofs of concept, starting from basic drafts to mastering the core pillars of OOP.

---

## Project Structure & Roadmap

* **V1: Draft / Initial Spike** — Basic syntax, dictionary operations, and initial class setup.
* **V2: Encapsulation**
* **V3: Inheritance and Polymorphism** 
* **V4: Abstraction**

#### Development Note: After mastering the fundamentals of OOP (completing V4), I will collaborate with a teammate to build a web application based on this business logic—a "sales app". I will be responsible for the backend, while my teammate will handle the frontend.
